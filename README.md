# Assambly-Digital-Clock
Project Title: 8086 Digital Alarm System

Language: Assembly (x86)

Environment: DOSBox / MASM 5.10

🔹 Overview
A low-level software implementation of a Digital Alarm Clock using 8086 Assembly language. This project demonstrates the use of hardware-level programming, interrupt handling (INT 21h), and modular code architecture (Procedures and Macros).

🔹 Key Features
Set Alarm: Custom input for hours and minutes with real-time validation.

Toggle Status: Dynamic switching between ACTIVE and INACTIVE states using bitwise XOR logic.

Input Validation: Prevents invalid time entries (e.g., hours > 23 or minutes > 59).

User Interface: Clean, menu-driven CLI (Command Line Interface).
